# Kingdom Two Crowns Takeover

**Minecraft** × Kingdom Two Crowns · visual · idea by the team

Bring Kingdom Two Crowns into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned Minecraft into Kingdom Two Crowns: coins make archers, towers rise, and masked Greed raid at night. The Breeder is huge!

## Install

Install Fabric with Fabric API for Minecraft Java, drop the mod jar in the mods folder and start a world. Right-click peasants with gold coins to hire archers, pay the gold signs to build, and survive the night.
